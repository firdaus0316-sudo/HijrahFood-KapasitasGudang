Pengaturan Akses Admin & Mode Umum (Operator)

Atur PIN Admin dan bagikan link khusus Mode Umum (hanya lihat KPI & Input Data Harian)

PIN disimpan di browser perangkat ini.

Hak Akses per Mode:

Mode Umum (Operator): Hanya melihat Ringkasan KPI, Grafik, dan mengisi Form Input Data Harian.

Mode Admin: Akses penuh ke tabel detail gudang, Database Log, Master Gudang, Export CSV, & Koneksi Sheet.

Koneksi Live Google Sheets (Apps Script)

Menghubungkan aplikasi lokal langsung ke DB_Chamber & DB_Reefer

Panduan Singkat (1x Setup):
  1. Di Google Sheets Anda, buka Extensions → Apps Script.
  2. Tempel kode dari tombol Salin Kode Apps Script di atas (atau file google_apps_script_Code.gs), lalu Save.
  3. Klik Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
  4. Salin Web App URL yang muncul lalu tempel ke kolom di atas.
